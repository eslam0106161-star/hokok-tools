# خط الأنابيب السحابي: من PDF إلى شرح وأسئلة أكاديمية

يشتغل بالكامل على سيرفرات GitHub (مجانًا، بلا حدود لأن الريبو Public) — تقفل موبايلك تمامًا وهو شغال.

## الإعداد (مرة واحدة بس)

1. **أضف مفتاح/مفاتيح Gemini API كـ Secret**، مش كإدخال عادي:
   - من صفحة الريبو على GitHub → **Settings** → **Secrets and variables** → **Actions**
   - اضغط **New repository secret**
   - **Name**: `GEMINI_API_KEYS`
   - **Value**: مفتاحك، أو أكتر من مفتاح مفصولين بفاصلة بدون مسافات، مثال:
     ```
     AIzaSy...key1,AIzaSy...key2
     ```
   - احفظ

## طريقة الاستخدام (كل مرة)

1. ارفع ملف الـ PDF بتاع الكتاب داخل مجلد `input/` في الريبو (استبدل أي ملف قديم فيه، أو ضيف كذا ملف مرة واحدة لو حابب يتعالجوا كلهم في نفس التشغيلة)
2. من تبويب **Actions** في الريبو، اختار الـ workflow اسمه **"توليد شرح وأسئلة من كتاب PDF"**
3. اضغط **Run workflow**، واختار الإعدادات (النموذج، طول الشرح، عدد الأسئلة...) أو سيبها الافتراضية
4. اضغط **Run workflow** الأخضر
5. **اقفل الموبايل عادي، مفيش داعي تستنى** — هيشتغل في الخلفية على سيرفرات GitHub
6. لما يخلص (هتوصلك حالته من نفس الصفحة، أو افتحها بعدين)، هتلاقي **Artifacts** تحت — حمّل `book-output-...` وهتلاقي جواه:
   - ملف `Word` جاهز فيه الشرح والأسئلة
   - ملف `.txt` بالنص الخام المستخرج (احتياطي)

## ملاحظات مهمة

- **صيغة العناوين المتوقعة في الكتاب**: "الباب الأول"، "الفصل الثاني"، "المبحث الثالث"... إلخ (نفس صيغة أداة `book-full-pipeline.html`)
- **الحد الأقصى لوقت التشغيل**: 6 ساعات (قيد من GitHub نفسه) — كافي جدًا لمعظم الكتب، لكن كتاب ضخم جدًا (مئات الصفحات + مئات الأجزاء) ممكن يحتاج وقت أطول من كده
- لو حصل خطأ أو توقف نفاد مفاتيح، شوف الـ Logs من نفس صفحة الـ run لمعرفة السبب بالتفصيل
